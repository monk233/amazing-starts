# amazing-starts

让 GitHub Stars 的管理与浏览变得 amazing。

`amazing-starts` 致力于帮助你更方便地浏览、分类和整理 GitHub 上收藏的开源项目，让收藏不再只是一个不断增长的列表。

## 项目目标

- 集中浏览 GitHub Stars，方便找到已收藏的项目。
- 按项目用途整理分类，并使用 GitHub Lists 管理收藏。
- 在保留已有收藏与分类的基础上，简化日常管理操作。

## 当前状态

项目处于初始化阶段，目前仅包含 README 和 MIT 许可证，尚未实现应用功能。上述内容为项目目标，不代表已经交付的功能。

项目名称保留为 `amazing-starts`；所管理的 GitHub 功能称为 Stars。
