# AI 服务配置准备

状态：准备说明。M1 尚未提供真实 AI 接入或凭证表单，没有发送任何 AI 请求。

## 需要用户自行提供的内容

- Base URL：用户选择的兼容聊天服务地址。
- API Key：仅在后续插件的真实配置页面输入，不发送到聊天，不写入项目文件。
- 模型名称：服务商实际支持且当前账号有权限调用的模型。

首版将实现一个明确的兼容聊天接口适配器。不同供应商的路径、认证和结构化输出支持必须在 M4 实测，不能仅凭服务名称宣称兼容。

## 地址与权限边界

普通服务仅使用 HTTPS；用户明确配置 loopback 本地服务时才支持对应 HTTP 地址。插件针对用户选择的 origin 请求可选主机权限，不默认获得所有网站访问权。

更换服务 origin 时，旧 Key 不自动转发到新地址。测试连接必须由用户主动触发，并提示可能产生费用。模拟测试成功不表示真实供应商连接成功。

## 数据边界

默认只发送当前操作所需的公开仓库信息和规则。私有仓库资料需要单独同意后才能发送。仓库 README 属于不可信数据，不能指示插件读取凭证或执行操作。

凭证默认仅保存在浏览器会话。只有用户明确选择“在此设备记住凭证”才持久保存。本地存储不是安全硬件保险箱；不要宣称凭证已加密或无法被本机访问。

## 未配置 AI 时

最终产品的手动管理不依赖 AI。M1 目前只有基础工程，不能把“未来手动管理无需 AI”误认为已经实现手动分类。

预览中的 Base URL 和模型名是不可编辑的视觉示例，不会被保存或测试。
