# AI 服务配置

真实扩展现已提供 Base URL、API Key、模型名称、测试连接和获取模型目录。视觉预览仍不连接服务。

## 使用入口

构建后，在 Chrome 扩展管理页加载 `.output/chrome-mv3`，打开扩展的管理页面，再进入“设置与准备”。普通网页或端口 4317 的视觉预览不能使用真实扩展 API。

1. 填写兼容服务的 API 根地址，例如 `https://your-provider.example/v1`，不要附加 `/models`。
2. 输入 API Key。默认仅保存在浏览器会话；只有主动勾选“在此设备记住凭证”才持久保存。
3. 保存配置。API Key 不回填到表单。
4. 点击“测试连接”或“获取模型目录”，按浏览器提示授权该服务主机。
5. 从目录选择模型，或手动填写模型 ID，再保存。

## 请求约定

- 仅支持 `Authorization: Bearer ...` 认证，以及 `GET {Base URL}/models`。
- 返回值需要包含 `data` 数组，每项具有字符串 `id`。
- “测试连接”验证同一个模型目录接口，不调用模型生成接口，不发送仓库内容。
- 模型目录可访问不等于模型生成可用；404 或格式不兼容不代表服务的其他接口不可用。
- 不支持模型目录的服务可以手动填写模型，但目前没有模型生成功能。
- 请求超时为 15 秒；模型目录响应最多 1 MiB、最多 5000 项。不接受重定向，不附带浏览器 Cookie。
- HTTP 状态错误、网络错误与超时有独立提示，不回显服务端原始错误内容。

## 地址、权限与凭证

普通服务仅允许 HTTPS；明确填写 `localhost` 或 `127.0.0.1` 时允许 HTTP。本版本要求填写 API Key，不支持无认证的本地服务。

扩展声明可选 HTTPS 主机范围及上述本地 HTTP 范围，但不会在安装或加载页面时请求全部网站权限。权限只在点击测试或获取目录时按当前服务主机申请。Chrome 主机权限不按端口隔离；凭证另行绑定完整的规范化 Base URL，包括端口和 API 路径。

更换完整 Base URL 后必须重新输入 Key，不自动转发旧 Key。切换地址不会自动撤销浏览器之前授予的主机权限，可在 Chrome 扩展设置中管理。API Key 不提供给 GitHub 内容脚本，也没有对界面开放读取凭证的消息接口。

配置与凭证当前是此设备的扩展设置，不属于尚未接入的 GitHub 账号。浏览器会话结束后，会话 Key 需要重新输入。勾选持久保存不等于加密保险箱；卸载或清除扩展数据可能丢失配置。

## 验证边界

自动化测试覆盖 URL 校验、会话与持久存储、地址变更、配置写入失败、消息授权、权限拒绝、HTTP 错误、响应格式、大小限制、超时及并发请求隔离。界面交互使用模拟扩展 API 检查，不代表真实 Chrome 授权对话框或外部服务已经验证。

不要把真实 API Key 发到聊天、写入项目文件或提交历史。真实供应商连通性需要你在加载的扩展中验证。
