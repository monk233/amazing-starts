# M0 视觉候选

日期：2026-10-09。状态：候选方案，等待用户确认默认方向；不是正式 UI 验收结论。

## 查看方式

在项目根目录执行 `pnpm preview:design`，访问 `http://127.0.0.1:4317/`。也可以直接在浏览器中打开本目录的 `preview.html`。

顶部可分别切换艺术方向与亮色、暗色、系统模式；侧栏可查看收藏页、仓库详情和设置。示例列表支持关键词搜索、分类筛选和打开详情。

这是独立的 HTML/CSS 交互视觉稿，不是应用完成度演示。它不连接 GitHub，不发送 AI 请求，不收集 API Key，也不修改真实收藏。6 条演示记录只用于检验布局与信息层级，描述和元数据不代表当前线上状态。

本环境没有可用的内置图像生成工具，未擅自使用需要 OPENAI_API_KEY 的 CLI 生图。两种方案使用代码原生的排版、几何标识和本地字体，无外链图片、纹理或付费生成资源。

## 方向 A：纸页收藏馆

- 语气：平静、有序、像自己的编辑目录。
- 亮色：暖纸底 `#f2f1ea`，内容面 `#fbfaf6`，深绿文字 `#283c30`，森林绿操作色 `#406047`。
- 暗色：墨绿背景与柔和的灰绿色文字，而非给亮色页面机械反相。
- 字体：品牌与少量英文展示文字使用 Fraunces；中文操作界面使用系统中文无衬线字体。
- 形态：目录式侧栏、扁平行列表、细分隔线、少量柔和圆角，避免卡片嵌套。
- 标识：清晰的四角星几何标记与书页线条，不使用位图插画或持续背景动画。
- 适合强调：阅读、私人收藏、手册与长期整理。

## 方向 B：轨道观测室

- 语气：清楚、有坐标感、像自己的探索工作台。
- 暗色：背景 `#101827`，内容面 `#182438`，文字 `#e9eef8`，琥珀强调 `#e7ba7f`。
- 亮色：蓝灰纸面、墨蓝文字和深蓝操作色，保持同一几何语言。
- 字体：品牌及英文仓库名称使用 Space Grotesk；中文操作界面使用系统中文无衬线字体。
- 形态：更利落的边角、清晰的行与列，使用克制的轨道几何图形表达分类关系。
- 适合强调：探索、项目对比、动态跟踪与开发工具。

两者不是简单的亮/暗色别名，每套方向均支持独立明暗模式。当前为了便于比较，预览共享相同的操作骨架；正式组件的密度、字体规模和品牌细节需在选定方向后继续收敛。

视觉预览中未实现的操作会明确说明“后续阶段接入”，不会伪装已经登录、已经分类或已经调用 AI。

## 交互与可访问性

按钮与链接有可见焦点，搜索结果和空结果真实响应本地演示数据。界面按 1440×900、1366×768 和 390×844 检查布局，窄屏转为顶部导航。

动效仅用于初次主区域轻微进入和控件反馈，遵循 prefers-reduced-motion。预览尚未经过完整的无障碍审计，不把机械检查结果等同于可访问性认证。

## 字体来源与授权

字体来自 `@fontsource-variable/fraunces@5.3.0` 和 `@fontsource-variable/space-grotesk@5.3.0` 的 Latin woff2 文件，本地保存在 `assets/`。原始授权文件同时保留，字体受其各自的 SIL Open Font License 约束，不由本项目的 MIT 声明替代。

本阶段字体仅用于设计预览，不增加实际扩展的运行时下载或构建体积。
